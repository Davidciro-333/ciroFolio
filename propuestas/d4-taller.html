How I think about it

Most of what I’ve built started as a pilot for one case and became a configurable platform. That transition is where the interesting decisions are: what becomes configuration, and what stays put.

Sales safeguards and payment validation don’t belong in a config file. Knowing where that line sits is the part nobody can improvise.

I work async-first, in Slack, Notion, pull requests and written docs. UTC-5 overlaps the whole US working day. And I run my own infrastructure, AWS EC2 behind nginx with Docker and self-hosted n8n, so I don’t need anyone else to deploy what I build.
